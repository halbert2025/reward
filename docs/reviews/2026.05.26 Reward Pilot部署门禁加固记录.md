# Reward Pilot 部署门禁加固记录

Date: 2026-05-26  
Stage: P9A / P9D Development Task

## Change

Strengthened `scripts/validate-env.mjs` so pilot/production environments fail fast when the external pilot safety gate is not satisfied.

## New Hard Gates

For `APP_ENV=pilot` or `APP_ENV=production`, validation now requires:

- `APP_BASE_URL` must use HTTPS.
- `REWARD_ADMIN_EMAILS` must be set.
- `ALLOW_DEMO_SEED` must not be `true`.
- `NOTIFICATION_MODE` must remain `in_app`.
- `REWARD_ENABLE_PAYMENTS` / `ENABLE_PAYMENTS` must not be `true`.

Existing hard gates remain:

- `AUTH_SECRET` must be 32+ characters.
- `DATABASE_URL` must be PostgreSQL.
- SQLite is forbidden for pilot/production.
- Mock role switcher must not be enabled.

## Tests

Added `tests/unit/validate-env.test.ts` covering:

- A valid locked-down pilot environment.
- HTTP URL and missing admin allowlist rejection.
- Demo seed, push notification, payment, mock role switcher, and SQLite rejection.

## Result

This closes one code-side part of the P9A/P9D gate. It still does not provide the missing hosted URL, PostgreSQL credentials, admin allowlist values, or named human operators.
