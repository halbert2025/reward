# Reward V1 范围重开评审报告

Date: 2026-05-26  
Stage: P12 V1 Scope Reopen

## Decision

V1 scope remains closed.

## Reason

P12 requires real pilot evidence after at least one feedback iteration. The project currently has internal readiness evidence but no external family feedback. Opening V1 now would be speculative and would risk expanding the product before the core family loop is proven.

## Outputs Created

- `docs/product/v1-scope-candidates.md`
- `docs/product/v1-not-now.md`
- `docs/decisions/v1-scope-decisions.md`

## Current V1 Policy

- Keep current MVP/Pilot scope.
- Fix only blockers for pilot launch.
- Do not add real AI, real photos, real push, payment, ranking, school workflows, or open child social.
- Reopen V1 only after first-batch feedback and P10 triage.

## Reopen Trigger

Run P12 again when:

1. At least 1-3 families complete pilot testing.
2. P10 feedback triage exists with real items.
3. P0/P1 issues are closed or pilot remains paused.
4. Privacy/safety review exists for each new candidate.
