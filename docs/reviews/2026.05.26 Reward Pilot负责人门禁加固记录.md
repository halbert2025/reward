# Reward Pilot 负责人门禁加固记录

Date: 2026-05-26  
Stage: P9D Development Task

## Change

Pilot/production environment validation now requires named human owners before deployment can pass.

## Required Owner Variables

- `REWARD_PILOT_OPS_OWNER`
- `REWARD_DATA_REQUEST_OWNER`
- `REWARD_SAFETY_REVIEW_OWNER`
- `REWARD_ROLLBACK_OWNER`

## Why

The P9D Go / No-Go gate requires clear ownership for pilot launch, data requests, safety/risk review, and rollback. These were previously documented but not enforceable by the deployment gate.

## Tests

Updated `tests/unit/validate-env.test.ts` to verify that missing owner variables fail in `APP_ENV=pilot`.

## Boundary

The variables are required only for `pilot` and `production`. Local development remains unaffected.
