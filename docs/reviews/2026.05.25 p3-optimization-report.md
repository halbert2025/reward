## 2. 具体优化

### 2.1 E2E helper

新增 `tests/e2e/helpers.ts`：

- `seedDemoData()`：每条 E2E 前重置 seed 数据。
- `useRole()`：通过 mock role cookie 切换 parent / child / witness。
- `completeChildContractFlow()`：复用 child 确认、番茄钟、复盘提交主链路。

### 2.2 Contract Flow

`tests/e2e/contract-flow.spec.ts` 现在覆盖：

- child 确认契约。
- child 启动猫咪番茄钟。
- child 完成并提交复盘。
- unsafe reward / contract input 被阻止进入 preview。

### 2.3 Fulfillment Flow

`tests/e2e/fulfillment-flow.spec.ts` 现在覆盖：

- parent 标记已兑现后生成 P10 日记。
- parent 延期后 witness 不能看到延期原因。
- parent 选择待复盘后创建 RepairCase，且不出现裁判/惩罚/责备表达。
- AuditLog 包含 `fulfillment_marked_fulfilled` 与 `diary_generated`。

### 2.4 Privacy Boundary

`tests/e2e/privacy-boundary.spec.ts` 现在覆盖：

- child 可以创建 ChildNote。
- parent 首页不能看到 child 私密 note 内容。
- witness 只能看到 safe summary。
- witness 看不到 ChildNote、evidence、amount、repair details。
- Kimi runtime endpoint 当前 MVP 未实现，保留明确 skip，避免假测试。

### 2.5 Playwright 配置

`playwright.config.ts`：

- `workers: 1`
- `fullyParallel: false`
- timeout 调整为 60 秒

原因：当前 MVP 使用共享 seed 数据和 SQLite，本阶段串行 E2E 更稳定，避免测试之间互相重置数据。
