## 2. 具体改动

### R2-002：E2E 仍全部 skip/TODO

- `tests/e2e/contract-flow.spec.ts` 已取消全局 skip。
- 新增每个测试前 `prisma:seed`，保证测试可重复。
- 当前覆盖：
  - child 确认契约。
  - child 启动猫咪番茄钟。
  - child 完成并提交复盘。
  - unsafe reward / contract input 被阻止进入 preview。
- `playwright.config.ts` 改为串行执行，避免测试之间共享 seed 数据时互相污染。

### R2-003：奖励/安全校验字段覆盖不足

- `RewardValidationInput` 新增：
  - `promiseText`
  - `repairText`
- `validateRewardInput` 现在统一检查：
  - title
  - promiseText
  - rewardText
  - taskText
  - evidenceText
  - repairText
- 新增单元测试覆盖 promise/repair 字段中的学校排名、支付钱包等禁用表达。

### R2-004：server action 仍偏 seed actor 硬编码

- `createOrReviseFirstContract` 读取 `getCurrentMockActor()`，非 parent/co_signer 会被拒绝。
- 修订契约时校验 actor 的 familyId，避免跨家庭或错误角色提交。
- `childConfirmFirstContract` 使用 `canConfirmContract` 校验当前 actor 必须是对应 child。
- `submitParentResponse` 使用 `canCreateFulfillment` 校验当前 actor 必须是对应家庭 parent/co_signer。
- 页面增加 `permission` 错误提示。
