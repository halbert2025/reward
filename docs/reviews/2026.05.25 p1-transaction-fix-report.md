# Reward P1 事务原子性修复记录

> 日期：2026-05-25  
> 对应复审问题：`R2-001 P09 家长回应到 P10 日记生成不是一个原子事务`  
> 涉及文件：`apps/web/lib/server/parent-response.ts`

## 1. 修复结论

`R2-001` 已修复。

P09 家长回应提交现在将以下操作放入同一个 Prisma interactive transaction：

- 重新读取并锁定语义上的待回应契约来源数据。
- 创建 Fulfillment。
- 如选择待复盘，创建 RepairCase。
- 创建 DiaryEntry。
- 将 Contract 更新为 `diary_generated`。
- 写入家长回应审计日志。
- 写入 `diary_generated` 系统审计日志。

事务中任何一步失败，前面已创建的 Fulfillment、RepairCase、DiaryEntry、Contract 状态和 AuditLog 都会一起回滚，避免出现“P09 查询不到、P10 又没有日记”的半截状态。

## 2. 额外修正

- `pending_repair` 分支的审计日志 `entityId` 现在指向真实 `RepairCase.id`，不再指向 Fulfillment id。
- 日记生成失败时不会先把 Contract 改成 `fulfilled` / `delayed` / `pending_repair` 后再卡住。
