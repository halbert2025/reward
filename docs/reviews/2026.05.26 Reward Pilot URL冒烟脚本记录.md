Date: 2026-05-26

## Change

Added `npm run pilot:url-smoke` for first-pass hosted pilot URL checks.

## Usage

```bash
npm run pilot:url-smoke -- https://<pilot-host>
```

Or:

```bash
PILOT_BASE_URL=https://<pilot-host> npm run pilot:url-smoke
```

## Checked Routes

- `/api/health`
- `/`
- `/auth/login`
- `/pilot/consent`
- `/feedback`
- `/privacy/requests`
- `/admin/pilot`
- `/witness`

## Boundary

The script requires HTTPS unless the target is `localhost` or `127.0.0.1`. It does not replace the full P9B user journey, screenshots, or permission-negative E2E; it is the first hosted URL gate.
