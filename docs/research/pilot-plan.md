# Reward MVP 灰度测试计划

本文用途：定义 Reward MVP 第一轮真实家庭测试的样本、流程、观察重点、中止条件和数据退出策略。本文不是法律意见；真实家庭测试前必须完成试用告知、监护人同意、儿童友好说明和目标市场法务审查。

## 1. 第一轮测试目标

第一轮只验证：

- 首个小约定闭环能否跑通。
- 家长是否理解产品不是审判工具。
- 孩子是否觉得这是愿望后院，而不是爸妈的任务表。
- 家长是否愿意在孩子完成后回应。
- 家庭是否愿意创建第二个约定。

第一轮不验证：

- 付费转化。
- 学校/机构路径。
- 商家导购。
- 真实 AI。
- 完整见证人分级。
- 长期能力归档。

## 2. 样本设计

| 项 | 方案 |
|---|---|
| 样本量 | 10-20 组家庭 |
| 招募来源 | 熟人家庭或明确愿意参与早期测试的家庭 |
| 孩子年龄 | 优先 8-12 岁 |
| 测试周期 | 7 天 |
| 参与角色 | 至少 1 位 parent + 1 位 child |
| 推荐场景 | 阅读、整理书桌、25 分钟专注、轻家务、运动打卡 |
| 排除场景 | 高冲突家庭、强控制诉求、涉及惩罚/羞辱/基础照顾条件化的任务 |

## 3. 测试前告知与同意

测试前必须说明：

- Reward 仍是测试版。
- 测试目的是验证家庭小约定闭环，不是评价家长或孩子。
- 系统会记录契约执行数据、状态、回应和基础使用事件。
- ChildNote / 树洞默认不向家长展示。
- 照片证据是可选的，应避免人脸、学校、住址和无关儿童信息。
- 家庭可随时退出测试。
- 退出后可选择数据封存、删除可删除内容或导出纪念摘要。
- 出现明确安全风险时，平台会按儿童安全 SOP 做人工复核。

需要获得：

- parent/监护人试用同意。
- child 友好说明后的知情同意表达。
- 对数据记录和访谈的同意。

## 4. 7 天测试节奏

| 时间 | 重点 |
|---|---|
| D0 | 完成家庭创建、原则确认、奖池初始化、首个小约定创建 |
| D1 | child 是否确认约定并开始守约 |
| D2 | child 是否完成并提交复盘，parent 是否回应 |
| D3 | 访谈一次轻量反馈：是否像审判/管理 |
| D4 | 观察是否自然查看亲子日记或愿望后院 |
| D5 | 引导但不强推第二个约定入口 |
| D6 | 观察第二个约定创建意愿和争议点 |
| D7 | 完成访谈、数据导出/封存/删除选择 |

## 5. 每日观察重点

产品行为：

- parent 是否完成首次设置。
- parent 是否能理解 5 条原则。
- parent 是否能创建首个小约定。
- child 是否愿意点击开始守约。
- child 是否完成番茄钟并提交复盘。
- parent 是否及时回应。
- 是否生成亲子日记。
- 是否创建第二个约定。

体验感受：

- 家长是否觉得被审判。
- 孩子是否觉得被管理。
- 孩子是否相信小纸条私密。
- 履约提醒是否温和。
- 愿望后院是否让孩子觉得努力被看见。

边界风险：

- 是否有人试图设置基础照顾、羞辱、惩罚、强控制类契约。
- 是否有人要求视频监督、强锁、定位。
- 是否有人上传人脸、学校、住址等照片。
- 是否出现明确安全风险。

## 6. 中止测试条件

出现以下情况，应中止该家庭测试或暂停新增约定：

- 家庭明确反馈产品加剧冲突。
- child 明显抗拒、焦虑、害怕或表示被监控。
- parent 试图把基础照顾、爱、安全、尊严作为奖励或惩罚。
- 出现 L4/L5 安全风险。
- 家庭要求停止测试。
- 测试人员发现数据或权限异常，例如 parent 能看到 ChildNote。
- 家庭要求真实支付托管、视频监督、强锁等违背产品边界的功能。

中止后：

- 停止新增约定。
- 保留必要安全记录。
- 提供封存/删除/导出选择。
- 安排简短退出访谈。

## 7. 数据删除/封存说明

测试结束或退出时，家庭可选择：

| 选择 | 说明 |
|---|---|
| 封存 | 不再提醒，不再推进，保留只读记录和纪念摘要 |
| 删除可删除内容 | 删除草稿、未发送内容、可删除展示内容；保留必要审计摘要 |
| 导出纪念摘要 | 导出 parent/child 可见的契约、完成记录和亲子日记摘要 |
| 安全记录保留 | 若触发安全流程，RiskSignal 和人工复核记录按 SOP 受限保留 |

不能承诺：

- parent 单方删除 child 已完成努力记录。
- 导出 ChildNote 给 parent。
- 删除依法或安全 SOP 需要保留的最小记录。

## 8. 第一轮通过标准

第一轮通过不要求所有指标漂亮，但至少需要：

- 大多数家庭能完成首次设置。
- 至少一半家庭跑通首个小约定。
- 家长访谈中“被审判感”不是主要负反馈。
- 孩子访谈中“被管理感”不是主要负反馈。
- 有家庭愿意创建第二个约定。
- 没有发生严重隐私或权限事故。

## 9. 输出物

第一轮结束后输出：

- 指标简报。
- 访谈摘要。
- 失败家庭路径分析。
- 文案问题清单。
- 隐私/安全问题清单。
- 是否进入第二轮 50-100 组测试的建议。
