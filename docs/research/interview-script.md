# Reward MVP 访谈脚本

本文用途：用于第一轮 10-20 组家庭测试后的访谈，判断 MVP 是否跑通首个小约定闭环，以及家长是否觉得被审判、孩子是否觉得被管理。

## 1. 访谈原则

- 不评价家长或孩子表现。
- 不追问 ChildNote 原文。
- 不让 child 在 parent 面前回答敏感感受。
- 先问开放问题，再问选择题。
- 记录原话时去标识化。
- 不采集学校、精确位置、真实姓名、无关人脸。

## 2. 家长访谈

### 理解与定位

1. 你能用一句话说出 Reward 是做什么的吗？
2. 你觉得它更像家庭约定工具、番茄钟、奖励表，还是监督工具？为什么？
3. 你觉得“把随口承诺，变成孩子相信的家庭约定”这句话是否准确？

### Onboarding

4. 创建家庭、确认原则、初始化奖池这几步哪里最卡？
5. 5 条原则有没有让你反感或有压力？
6. 奖池初始化是否帮你想清楚哪些奖励适合，哪些不适合？

### 审判感

7. 孩子完成后收到回应提醒时，你觉得它是在帮助你记得回应，还是像在审判你？
8. 哪一句文案最让你舒服？哪一句让你有压力？
9. 如果你需要延期，填写原因和新时间会不会让你反感？

### 契约价值

10. 创建第一个小约定是否足够简单？
11. 你觉得孩子是否更清楚自己在为什么努力？
12. 你是否愿意创建第二个约定？如果不愿意，原因是什么？

### 隐私与边界

13. 你是否理解 ChildNote / 小纸条默认不向家长展示？
14. 这个边界会让你更信任产品，还是觉得不放心？
15. 你是否期待视频监督、强锁、支付托管或学校功能？为什么？

## 3. 孩子访谈

访谈 child 时，尽量让 parent 不在旁边直接听。

### 体验定位

1. 你觉得这是你的愿望后院，还是爸妈给你的任务表？
2. 你知道自己是在为哪个愿望努力吗？
3. 你喜欢小院和安静猫来访吗？哪里可以更好？

### 守约过程

4. 开始守约按钮好理解吗？
5. 25 分钟番茄钟会不会太长或太短？
6. 如果中途停下，写原因会不会有压力？
7. 完成后写一句复盘难不难？

### 被管理感

8. 你觉得这个 App 像是在记录你的努力，还是像在管你？
9. 有没有哪个地方让你觉得不舒服、紧张或被盯着？
10. 你会愿意下次继续用吗？

### 隐私信任

11. 你相信小纸条默认只有自己能看吗？
12. 如果你想把一句话分享给家长，你希望怎么确认？
13. 你不希望家长或见证人看到哪些内容？

## 4. 共同复盘问题

parent 和 child 可一起回答：

1. 这个约定一开始说清楚了吗？
2. 完成后回应是否及时？
3. 亲子日记是否值得保存？
4. 如果再创建第二个约定，你们会选什么愿望？
5. 这个产品有没有让你们少争吵一点？

## 5. 观察者记录表

| 观察项 | 记录 |
|---|---|
| 家长是否能准确描述产品定位 | 是/否/部分 |
| 家长是否出现被审判感 | 无/轻微/明显 |
| 孩子是否出现被管理感 | 无/轻微/明显 |
| 孩子是否理解愿望后院 | 是/否/部分 |
| 家长是否愿意创建第二个约定 | 是/否/犹豫 |
| child 是否愿意继续使用 | 是/否/犹豫 |
| 是否出现隐私担忧 | 无/有 |
| 是否出现产品边界误解 | 无/有 |
| 是否出现中止条件 | 无/有 |

## 6. 不应提问

不要问：

- 你是不是不守信用？
- 你是不是不认真？
- 你有没有偷偷写了什么？
- 爸爸妈妈有没有让你害怕？
- 你想不想举报家长？
- 你学校叫什么？
- 你家住哪里？
- 你能发一张照片证明吗？

如 child 主动表达安全风险，转入 `docs/safety/child-safety-sop.md` 的人工复核流程。
