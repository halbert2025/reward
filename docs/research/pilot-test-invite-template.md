# Reward 第一批测试家庭邀请模板

日期：2026-05-26  
适用范围：Alpha / Pilot 第一批受控测试家庭  
使用前提：仅发送给已明确愿意参与小范围测试的家庭；正式对外长期开放前仍需法律/隐私文本复核。

## 1. 给家长的邀请消息

你好，我们准备邀请少量家庭试用 Reward 的第一版测试体验。

Reward 是一个“家庭小约定 + 温和兑现 + 亲子记忆”的工具，不是监控、惩罚或排名软件。第一版主要想验证一件小事：家长和孩子能不能一起完成一个清楚、轻量、可回看的小约定。

这次测试会包含：

- 家长登录并创建家庭。
- 家长邀请孩子加入。
- 家长创建一个 25 分钟小约定。
- 孩子确认约定，使用猫猫奶茶厅番茄钟完成一次专注。
- 孩子提交一句复盘。
- 家长选择兑现、延期或待复盘。
- 系统生成一条家庭日记和孩子的小票收藏记录。
- 家庭可提交反馈、退出测试、申请导出/删除/封存数据。

这次测试不会包含：

- 不上传真实照片。
- 不使用摄像头、定位、锁机或网站屏蔽。
- 不做排名、公开社交、抽奖或付费。
- 不接入真实 AI/Kimi，也不会把孩子私密内容发给外部模型。
- 不让见证人看到孩子复盘原文、ChildNote、证据细节或金额信息。

如果你愿意参与，我们会发你测试地址和登录方式。第一次使用前，请先阅读并确认页面里的测试告知与同意说明。测试过程中，你可以随时反馈问题，也可以申请退出测试。

建议测试方式：

1. 选择一个低压力小愿望，不要选高金额或容易争吵的目标。
2. 让孩子自己决定什么时候开始番茄钟。
3. 完成后先看孩子的一句复盘，再做家长回应。
4. 如果觉得哪里不舒服、不公平或不好理解，直接在反馈页告诉我们。

## 2. 给孩子的说明

这是一个帮家里记住“小约定”的测试版。

你可以做的事：

- 看清楚这次小约定是什么。
- 自己点开始。
- 用猫猫奶茶厅番茄钟完成一次安静的 25 分钟。
- 写一句刚才做了什么。
- 看自己的猫猫小票收藏。
- 写只给自己看的私密小纸条。

你需要知道：

- 这里没有排名。
- 不会打开摄像头。
- 不会定位你。
- 不会锁住设备。
- 你的小纸条默认只给你自己看。
- 如果你觉得不舒服，可以告诉家长或可信任的大人。

## 3. 测试前确认清单

发送测试邀请前，运营人员需要确认：

- [ ] 已告知这是测试版，不是正式长期服务。
- [ ] 已说明第一版不上传真实照片。
- [ ] 已说明 AI/Kimi 默认关闭。
- [ ] 已说明可以退出测试。
- [ ] 已说明可申请导出、删除、封存数据。
- [ ] 已说明 ChildNote 默认孩子私密。
- [ ] 已说明见证人只看安全摘要。
- [ ] 已提供反馈入口：`/feedback`。
- [ ] 已提供数据请求入口：`/privacy/requests`。

## 4. 测试后反馈问题

建议向测试家庭收集这些问题：

- 家长能否独立完成登录、创建家庭和邀请孩子？
- 孩子是否能看懂约定并自己开始？
- 番茄钟是否足够安静，不抢注意力？
- 家长回应是否温和清楚？
- 奖励小票是否像“记录努力”，而不是“评分”？
- 哪些文案让人不放心或看不懂？
- 有没有任何隐私、安全或家庭关系上的担心？

## 5. 退出测试说明

测试家庭可以随时退出。退出时可选择：

- 只停止继续使用，保留已有测试记录。
- 申请导出家庭可见数据。
- 申请封存家庭数据。
- 申请删除评审，按人工流程处理。

退出、导出、删除和封存请求统一从 `/privacy/requests` 提交，由内部运营在 `/admin/pilot` 处理并留下审计记录。
