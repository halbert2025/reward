## Parent Start Steps

1. Open the pilot link.
2. Log in or enter the provided test access method.
3. Read and confirm the pilot consent notice.
4. Create your family.
5. Invite your child with the child code.
6. Create one low-pressure agreement.
7. Let the child confirm and start when ready.
8. Respond after the child submits a reflection.
9. Use `/feedback` if anything is confusing.
10. Use `/privacy/requests` for export, deletion review, sealing, or exit.
