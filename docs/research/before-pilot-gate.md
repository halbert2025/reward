# Before Pilot Gate

Reward MVP is approved for internal desktop demo only until this gate is closed.

## Required Before Real Families

- [ ] Guardian consent text reviewed and attached to the pilot invite flow.
- [ ] Minor data handling and privacy policy draft reviewed by a legal/privacy owner.
- [ ] Evidence-photo rules finalized, including face, address, school-logo, and sensitive-location guidance.
- [ ] Manual export, seal, deletion, and retention workflow assigned to an operator.
- [ ] Manual review workflow for abnormal emotion or explicit safety-risk signals assigned to an operator.
- [ ] Test-family exit workflow documented, including what data is deleted, sealed, or exported.

## Product Constraint

The current codebase must keep Kimi/AI as a mock or template boundary by default. Any real AI connection must be opt-in, redact child/private content before the request, provide a visible off switch, and degrade to template text on failure.
