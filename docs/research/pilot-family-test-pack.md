# Reward Pilot Family Test Pack

Date: 2026-05-26  
Stage: P9C First Test User Handoff Pack

## What This Test Is

Reward is a gentle family contract tool. It helps a parent and child make one small agreement, complete a calm focus session, record a short reflection, and keep a family memory.

This pilot is not a monitoring, punishment, ranking, payment, or device-control tool.

## Test Scope

Please test one small agreement:

1. Parent opens the pilot link.
2. Parent logs in or enters the test access method.
3. Parent reads and confirms the pilot consent notice.
4. Parent creates a family.
5. Parent invites the child.
6. Child joins with the invite code.
7. Parent creates one small agreement.
8. Child confirms it.
9. Child uses the cat teahouse pomodoro.
10. Child submits a short reflection.
11. Parent responds with fulfill, delay, or repair.
12. Family reviews the generated diary.
13. Optional: parent creates a witness memory link.

## Please Do Not Enter

- Child real full name.
- School, class, home address, phone number, ID number.
- Face photos, school logos, certificates, location screenshots.
- Chat screenshots.
- High-value cash rewards.
- Anything that would make the child feel monitored or punished.

## Child-Friendly Note

This is a small test garden for family promises. The cat timer is only there to keep quiet company. It does not lock the device, rank you, record your camera, or track your location.

Your private note is meant to stay private by default. If anything feels uncomfortable, stop and tell a trusted adult.

## Success Signal

The test is useful if one family can complete one low-pressure agreement and tell us:

- Where the flow was clear.
- Where the flow was confusing.
- Whether the cat pomodoro felt calm.
- Whether the privacy wording felt trustworthy.
