# Reward MVP 指标

本文用途：定义 Reward MVP 是否值得进入真实家庭测试和继续开发的核心指标。MVP 不追求大规模增长，优先验证首个小约定闭环、家长回应、孩子参与感和第二个约定意愿。

## 1. 北极星问题

MVP 要回答：

- 一个家庭能否在 5 分钟内创建第一个小约定？
- 孩子是否愿意主动开始守约？
- 家长是否愿意回应兑现/延期/复盘？
- 完成后是否生成了让双方愿意保存的亲子日记？
- 家庭是否愿意创建第二个约定？

## 2. 核心指标

| 指标 | 定义 | 分子 | 分母 | 判断意义 |
|---|---|---|---|---|
| 首次设置完成率 | parent 完成原则确认和奖池初始化比例 | `principles_confirmed` 且 `reward_pool_created` 的 family 数 | `family_created` 的 family 数 | onboarding 是否过重 |
| 首个小约定创建率 | 完成设置后创建首个约定比例 | 创建首个 `contract_created` 的 family 数 | 完成首次设置的 family 数 | 家长是否理解价值 |
| 孩子开始守约率 | child 确认愿望后点击开始比例 | 有 `focus_started` 的首个 contract 数 | 有 `contract_confirmed` 的首个 contract 数 | 孩子端是否有参与感 |
| 首个约定完成率 | child 完成番茄钟并提交复盘比例 | 有 `task_submitted` 的首个 contract 数 | 有 `focus_started` 的首个 contract 数 | 任务设计是否合理 |
| 家长回应率 | child 达成后 parent 选择兑现/延期/待复盘比例 | 有 `fulfillment_responded` 的首个 contract 数 | 有 `task_submitted` 的首个 contract 数 | 履约提醒是否有效 |
| 亲子日记生成率 | 约定完成后生成日记比例 | 有 `diary_created` 的首个 contract 数 | response_type 为 `fulfilled` 的首个 contract 数 | 情感闭环是否达成 |
| 第二个约定创建率 | 家庭创建第二个约定比例 | 创建第 2 个 `contract_created` 的 family 数 | 完成首个闭环的 family 数 | 最关键，验证不是新鲜感 |
| 7 日家庭留存率 | 7 日内有至少一次有效行为 | 第 7 天仍有有效事件的 family 数 | D0 激活 family 数 | 短期留存 |

## 3. 有效行为定义

有效行为包括：

- 创建或确认约定。
- 开始或完成愿望番茄钟。
- 提交复盘。
- parent 回应兑现/延期/待复盘。
- 查看或生成亲子日记。
- 创建第二个约定。

不计入有效行为：

- 单纯打开页面。
- 反复切换 mock role。
- 触发错误页面。
- 访问权限不足页面。

## 4. 第一轮观察阈值

第一轮 10-20 组家庭样本小，阈值只作为方向，不作统计显著结论。

| 指标 | 绿色信号 | 黄色信号 | 红色信号 |
|---|---|---|---|
| 首次设置完成率 | >= 70% | 40%-69% | < 40% |
| 首个小约定创建率 | >= 70% | 40%-69% | < 40% |
| 孩子开始守约率 | >= 60% | 30%-59% | < 30% |
| 首个约定完成率 | >= 50% | 25%-49% | < 25% |
| 家长回应率 | >= 70% | 40%-69% | < 40% |
| 亲子日记生成率 | >= 80% | 50%-79% | < 50% |
| 第二个约定创建率 | >= 30% | 10%-29% | < 10% |
| 7 日家庭留存率 | >= 40% | 20%-39% | < 20% |

## 5. 定性判断

必须结合访谈判断：

- 家长是否觉得产品在审判自己。
- 孩子是否觉得产品在管理自己。
- 原则确认是否让家庭觉得可信而不是压力。
- 孩子是否把愿望后院当作自己的空间。
- 家长是否认为回应提醒温和。
- 家庭是否愿意自然创建第二个约定。

## 6. 不用作 MVP 成败的指标

第一轮不看：

- 付费转化率。
- 裂变分享率。
- 见证人传播率。
- 长期能力归档。
- AI 使用率。
- 小院装饰深度。

原因：这些属于 V1/V2 或商业化验证，不应干扰 MVP 闭环判断。
