# Reward 开放问题清单

本文用途：记录 Reward 进入开发前仍需确认的问题，并按阻塞级别管理。任何开发任务遇到未冻结事项时，必须引用本文件的问题编号，不得自行扩大 MVP 范围。

状态说明：

- `Closed`：已在 Prompt 0B 中形成可开发假设。
- `Open`：仍需在指定阶段前确认。
- `Deferred`：明确后置，不阻塞 MVP。
