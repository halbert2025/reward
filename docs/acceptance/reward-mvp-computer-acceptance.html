Reward MVP 电脑端验收文件

日期：2026-05-25。用途：在本机浏览器验收 Reward MVP Demo。

启动方式

在 D:\AIprojects\reward 目录执行：

npm.cmd run dev

打开：http://localhost:3000

主要页面入口

家长 onboarding

创建首个小约定

猫咪愿望后院

孩子私密小纸条

家长兑现回应

纪念见证人邀请

见证人视图

验收脚本

  1. 家长进入 onboarding，完成家庭、五条原则、奖池初始化。
  2. 家长进入“创建首个小约定”，选择小愿望，生成预览。
  3. 孩子打开确认页，确认约定。
  4. 孩子进入猫咪愿望后院，点击“开始守约”。
  5. 猫咪番茄钟显示 25 分钟产品承诺，调试倒计时结束后点击“我完成了”。
  6. 孩子提交一句复盘，可选照片占位。
  7. 家长打开“家长兑现回应”，选择已兑现、延期或一起复盘。
  8. 系统生成亲子日记，日记包含愿望、任务、孩子复盘、家长回应、完成时间、安静猫来访文案。
  9. 孩子在“小纸条”写一条私密内容，确认父母和见证人页面不显示正文。
  10. 家长生成一个纪念见证人邀请，见证人只能看到摘要并发送一句祝福。
