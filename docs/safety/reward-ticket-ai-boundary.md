# 奖励小票与 AI/Kimi 边界

日期：2026-05-26  
范围：MVP / Pilot

## 1. 当前结论

奖励小票和番茄钟复盘文本在 MVP 中不外发给 Kimi 或其他真实 AI。当前小票文案来自孩子主动提交的反思和本地模板，不使用真实外部模型生成、改写或评价。

## 2. 禁止外发内容

- ChildNote 原文。
- 真实照片、EXIF、地理位置、学校标识、人脸。
- 孩子的完整复盘原文，除非未来有单独同意、脱敏和人工确认流程。
- 任何用于判断孩子“好坏”“是否撒谎”“谁对谁错”的上下文。

## 3. 未来接入前置条件

真实 Kimi 或其他 AI provider 接入奖励小票前，必须满足：

- `AI_PROVIDER_MODE` 默认仍为 `mock` 或 `template`。
- staging 手动开启真实 provider，production 不默认开启。
- 家长额外知情并可关闭。
- 请求前脱敏，且不得包含 ChildNote、照片、位置、学校、住址。
- 失败时降级到本地模板，不阻断主流程。
- AI 输出只作为建议，必须由用户确认后才可保存。
- 写入最小化审计轨迹，不记录完整敏感 prompt。

## 4. 验收要求

- `tests/e2e/privacy-boundary.spec.ts` 保持 Kimi runtime 边界检查。
- 若新增 AI endpoint，必须增加“奖励小票复盘文本不外发未脱敏原文”的测试。
- 文案不得暗示 AI 会裁判、自动报警、自动通知家长或替家庭决定。
