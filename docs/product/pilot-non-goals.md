# Reward 测试用户版本不做清单

日期：2026-05-25  
阶段：Alpha / Pilot Readiness

## 1. 本阶段原则

测试用户版本优先解决“能安全给少量家庭试用”的问题，不扩展会增加合规、隐私、运营和测试复杂度的功能。

## 2. 明确不做

| 不做项 | 原因 | 替代方案 |
| --- | --- | --- |
| 原生 App | 会增加打包、审核、更新和设备兼容成本 | 先做 Web / 移动浏览器适配 |
| 真实推送通知 | 需要额外权限、退订、触达合规和失败处理 | 先做站内通知和页面状态 |
| 真实 AI/Kimi 自动建议 | 涉及未成年人数据外发和失败降级 | 默认 mock/template |
| AI 裁判 | 家庭争议不能交给模型判断 | AI 只可建议、转述、拆解 |
| 证据照片真实上传 | 第一批测试不需要高风险儿童影像数据 | 先用文字说明/mock placeholder |
| 支付、钱包、托管 | 涉及未成年人支付和资金监管 | 只记录承诺和兑现提醒 |
| 商家奖励池 | 会引入导购动机和商业信任问题 | 只支持家庭自定义愿望 |
| 会员/Pro | 会干扰试点目标 | 后续再评估 |
| 学校/机构场景 | 会变成教育管理和排名系统 | 只做家庭场景 |
| 视频监控 | 高隐私风险，会破坏儿童信任 | 使用轻量复盘和家长确认 |
| 默认强锁手机 | 容易滑向控制软件 | 孩子主动开始番茄钟 |
| 开放儿童社交 | 隐私和陌生人风险高 | 不开放 |
| 排行榜/攀比 | 不符合低压力家庭契约定位 | 使用个人家庭日记 |
| 抽卡式惊喜 | 对未成年人有概率刺激风险 | 使用温和完成反馈 |
| 大规模数据分析 | 第一批样本小，容易误读 | 只看试点质量指标 |

## 3. 可延后讨论

以下功能不是当前版本阻塞项：PWA 安装体验、低攀比灵感库、能力归档、时光邮局、自愿专注护盾、家庭年度回顾、更多猫猫番茄钟主题。

## 4. 代码审查底线

如果开发中出现以下内容，必须阻止合并：

- parent 默认读取 ChildNote 原文。
- witness 可读取证据、ChildNote、金额、修复争议详情。
- 真实 AI 在未脱敏、未告知、不可关闭的情况下接入。
- 生产环境依赖 seed_family / seed_parent / seed_child。
- 未经同意创建真实测试家庭数据。
- 删除或封存请求没有审计记录。
- 出现学校、机构、支付、导购、视频监控、强锁、开放儿童社交主链路。
