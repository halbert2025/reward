# Reward V1 Not-Now List

Date: 2026-05-26  
Stage: P12 V1 Scope Reopen

The following items remain outside V1 until real pilot evidence changes the decision.

## Not Now

- Real photo upload.
- Real push notifications.
- Real AI/Kimi processing of child or evidence content.
- Payment, escrow, shopping, merchant coupons.
- Ranking, streak pressure, public comparison.
- Open child social features.
- School, class, institution, or teacher workflows.
- Device lock, app blocking, camera monitoring, location tracking.
- High-value reward marketplace.

## Why

These features increase compliance, privacy, safety, or family-pressure risk before the core loop has enough real-world evidence.

## Reopen Rule

Reopen only after:

1. At least one real pilot feedback iteration.
2. No open P0/P1 pilot issues.
3. Clear user evidence.
4. Explicit privacy/safety review.
