# Reward MVP 产品冻结稿

本文用途：冻结 Reward MVP 的产品目标、用户角色、核心页面、功能边界、数据与隐私底线、AI 边界和 Demo 成功标准。后续 AGENTS、状态机、数据模型、API、测试和前端实现都以本文为准。

- `docs/source/extracted/html-prototype-notes.md`

## 1. 一句话定位

把随口承诺，变成孩子相信的家庭约定。

## 2. 产品定义

Reward 是面向家庭端的亲子愿望契约产品。它把家庭中的口头承诺转化为结构化、可执行、可记录、可提醒、可修复、可归档的家庭约定。

Reward 的产品本质：

- 家庭契约系统。
- 愿望驱动系统。
- 轻证据系统。
- 成长记录系统。

Reward 不是：

- 家长控制软件。
- 学校管理工具。
- 机构完课工具。
- 奖励商城。
- 支付托管平台。
- 儿童社交平台。

## 3. 产品人格

| 人格 | 含义 | MVP 表现 |
|---|---|---|
| 家庭契约教练 | 帮家庭把目标、奖励、证据、兑现时间说清楚 | 原则确认、奖池初始化、首个小约定模板 |
| 温柔史官 | 如实记录原始契约、努力过程和家长回应 | ContractVersion、AuditLog、DiaryEntry |
| 协商主持人 | 争议时回到原始规则，不判谁赢 | 家长回应保留“待复盘”入口 |
| 孩子努力保护者 | 孩子完成过的努力不能被单方抹掉 | 禁止 parent 硬删努力记录，保留封存路径 |
| 愿望世界建设者 | 让孩子感觉努力会改变自己的愿望世界 | 愿望后院、安静猫来访、纪念卡 |

## 4. 首批目标用户

| 维度 | MVP 冻结 |
|---|---|
| 孩子年龄 | 8-12 岁 |
| 家长类型 | 愿意讲规则、愿意兑现承诺，但缺少结构化工具的家长 |
| 家庭场景 | 学习专注、阅读、整理、日常习惯、小愿望兑现 |
| 不适配用户 | 强控制型、拒绝协商型、长期不履约且不愿修复的家长 |
| 测试重点 | 第二个约定创建率、孩子开始守约率、家长回应率 |

## 5. MVP 唯一核心闭环

```text
家长创建家庭
→ 家长确认 5 条家庭契约原则
→ 家长通过 3-4 个情境问题初始化简版奖池
→ 系统推荐首个小约定：25 分钟愿望番茄钟
→ 家长邀请孩子进入孩子端
→ 孩子选择小愿望并确认约定
→ 孩子主动点击“开始守约”
→ 孩子完成番茄钟，提交一句复盘，可选照片
→ 家长收到待回应提醒
→ 家长选择已兑现 / 延期 / 待复盘
→ 系统生成亲子日记
→ 愿望后院出现安静猫来访
```

MVP 不验证完整平台，只验证这一个小闭环是否能让家庭愿意创建第二个约定。

## 6. MVP 用户角色

| 角色 | 定位 | MVP 权限 | MVP 限制 |
|---|---|---|---|
| parent | 家庭创建者、奖池设定者、履约回应者 | 创建家庭、确认原则、初始化奖池、创建约定、查看契约执行记录、回应兑现/延期/待复盘、邀请纪念见证人 | 不能查看 ChildNote；不能单方硬删孩子努力记录；不能覆盖已确认 ContractVersion |
| child | 愿望选择者、守约执行者、成长记录拥有者 | 选择家庭奖池中的小愿望、确认约定、开始守约、提交复盘/轻证据、查看自己的努力记录、写 ChildNote | 不能自由开价；不能修改已确认契约；不能随意邀请陌生人 |
| witness | 纪念见证人 | 查看契约摘要和完成纪念，发送一句祝福 | 不看金额、证据、树洞、争议详情；不裁定 |
| system | 史官、提醒器、状态机执行者 | 写状态、通知、AuditLog、DiaryEntry | 不裁判、不自动发送关键内容、不替任何一方决定 |

## 7. MVP 十个页面

| 编号 | 页面 | 核心内容 | Done When |
|---|---|---|---|
| P01 | 家长欢迎页 | 主标题、副标题、三卖点、创建入口 | 家长 30 秒内理解它是家庭约定闭环，不是番茄钟 |
| P02 | 原则确认页 | 5 条家庭契约原则 | 未确认原则不能创建正式契约 |
| P03 | 奖池初始化页 | 小/中/大愿望边界，禁用奖励偏好 | 生成 RewardPool，孩子只能从家庭池选择 |
| P04 | 创建首个小约定页 | 愿望、任务、证据、奖励、兑现时间 | 生成 Contract draft 和 ContractVersion |
| P05 | 孩子邀请页 | 邀请码/二维码/链接 | child 可进入确认 |
| P06 | 孩子愿望后院首页 | 当前愿望、小院、猫猫占位、开始守约 | 孩子知道自己在为哪个愿望努力 |
| P07 | 愿望番茄钟页 | 开始、倒计时、中途退出原因、完成 | child 主动开始；退出需写原因 |
| P08 | 完成提交页 | 一句复盘、可选照片 | Task 更新，Evidence/复盘写入 |
| P09 | 家长兑现提醒页 | 已兑现、延期、待复盘、留言 | 家长不能无回应关闭任务 |
| P10 | 亲子日记页 | 愿望、任务、复盘、家长回应、猫猫来访 | 生成 DiaryEntry，parent/child 可见 |

## 8. MVP 必做功能

### 家庭与原则

- parent 创建家庭。
- parent 添加 child 档案：昵称、年龄段、孩子端邀请码。
- parent 确认 5 条原则：
  - 签约后不能单方修改验收标准。
  - 孩子完成约定后，应兑现或协商延期。
  - 基础照顾、爱、陪伴和安全不能作为奖励或惩罚。
  - 本 App 不是控制孩子的工具，而是帮助家庭建立清楚规则。
  - 孩子有权对不公平的约定提出反馈。

### 奖池与愿望

- 简版小/中/大奖池初始化。
- 禁用奖励类型：现金、游戏充值、盲盒、高价电子产品、过长屏幕时间等。
- child 只能从家庭奖池中选择首个小愿望。

### 契约与状态

- 首个小约定默认模板：25 分钟愿望番茄钟。
- 契约字段：愿望、任务、证据、奖励、兑现时间、延期规则。
- Contract 状态：draft、pending_confirmation、active、achieved、fulfilled、delayed、pending_repair、archived。
- ContractVersion 必须存在，已确认契约不可覆盖。
- 所有关键状态转换必须写 AuditLog。

### 孩子端守约

- 愿望后院首页。
- 主动开始守约。
- 中途退出原因。
- 完成后提交一句复盘。
- 可选轻证据照片。
- 安静猫来访。

### 家长回应与记忆

- 孩子完成后 parent 收到待回应。
- parent 可选已兑现、延期、待复盘。
- 延期必须填写原因和新兑现时间。
- 已兑现后生成亲子日记。
- parent 可写一句留言。

### 隐私与见证

- ChildNote MVP 最小版：child 可写给自己，默认只有 child 可见。
- 1 个免费纪念见证人占位。
- witness 只能看摘要和完成纪念，可发送一句祝福。

## 9. MVP 明确不做

- 学校、老师、机构、班级、小区、兴趣班路径。
- 支付托管、奖励钱包、资金池、礼品卡、现金红包、平台代买奖励。
- 商品导购、商家赞助、商品抽佣、孩子端商业推荐。
- 视频监督、全天监控、默认强锁、实时定位。
- 开放儿童社交、评论、点赞排名、排行榜、陌生人关注、同校/班级数据池。
- 抽卡、爆率、SSR、十连、保底、欧皇、氪金、付费随机。
- 完整 AI、AI 裁判、AI 自动发送、AI 自动报警。
- 完整约定修复中心。
- 完整见证人分级。
- 低攀比灵感库。
- 能力归档。
- 时光邮局。
- 年度报告。
- 小院名片分享。

## 10. V1 / V2 / 长期路线

| 版本 | 目标 | 做什么 | 不做什么 |
|---|---|---|---|
| MVP | 跑通首个家庭小约定闭环 | 原则确认、简版奖池、25 分钟愿望番茄钟、轻证据、兑现提醒、亲子日记、猫猫小院雏形、1 个纪念见证人 | 强锁、视频、开放社交、学校、机构、托管、商家、同龄数据池 |
| V1 | 成为家庭日常契约系统 | 完整奖池、目标奖励匹配、任务分类、能力归档、约定修复、见证人 H5、时光邮局、猫猫后院 1.0、会员体系 | 开放社区、商家推荐、支付托管、学校机构 |
| V2 | 形成壁垒和传播 | 家庭汇率模型、低攀比匿名灵感库、小院名片、轻社交、手表接入、自愿专注护盾、年度报告、多皮肤 | 孩子端导购、排行榜、抽卡、同校数据池 |
| 长期 | 深化家庭契约和成长档案 | 家庭成长报告、个人史官、孩子成年后档案转移 | 不卖孩子愿望、不卖家长焦虑、不做控制软件、不做学校/机构/商家路径 |

## 11. MVP 归属矩阵

| 事项 | MVP 结论 | 依据/说明 |
|---|---|---|
| Web/PWA 首版 | 进入 MVP | 开发和演示成本最低，真实移动端壳后置 |
| 真实登录 | 不进入 MVP | Demo 可用 mock role switcher，真实登录进入后续技术任务 |
| 简版奖池初始化 | 进入 MVP | 3-4 个情境问题生成小/中/大奖池边界 |
| 孩子自由开价 | 不进入 MVP | 首版只允许从家庭奖池选首个小愿望 |
| 首个 25 分钟愿望番茄钟 | 进入 MVP | 唯一核心闭环 |
| 照片证据 | 进入 MVP 但可 mock 存储 | 只作为可选轻证据，必须提示隐私最小化 |
| 默认自动通过 | 进入 MVP | 小任务孩子提交后进入家长回应，避免审核负担过重 |
| 家长回应：已兑现/延期/待复盘 | 进入 MVP | 完成闭环必需 |
| 约定修复中心 | 不进入 MVP | V1 功能，MVP 只保留“待复盘”状态入口 |
| 免费 1 个纪念见证人 | 进入 MVP 占位 | 只看摘要和纪念，不看金额/证据/争议/树洞 |
| 完整见证人 H5 | 不进入 MVP | V1 功能 |
| ChildNote/树洞默认私密 | 进入 MVP 底线 | 可有最小入口或数据模型，但家长不可见 |
| 真实 AI | 不进入 MVP | 首版用规则模板和 mock AI |
| AI 裁决/自动报警/自动发送 | 永久不作为默认能力 | 与产品中立和儿童信任冲突 |
| 支付托管/钱包/红包 | 不进入 MVP | 碰资金池和未成年人支付风险 |
| 学校/机构/老师端 | 不进入 MVP，且不进入默认路线 | 只做家庭端 |
| 视频监督/实时监控/默认强锁 | 不进入 MVP | 只做孩子主动开始的契约式专注 |
| 开放儿童社交/排行榜/评论/私信 | 不进入 MVP | 隐私、攀比和审核风险过高 |
| 商家导购/商品抽佣 | 不进入 MVP，且不作为商业化路径 | 商业化只从家庭订阅开始 |

## 12. 数据与隐私底线

- A/B/C/D/E 数据分级必须进入工程设计。
- ChildNote 与 Evidence 必须分开。
- ChildNote 默认属于 child，parent/witness 不可见。
- Evidence 按契约验收协议可见，最小化采集。
- 家长可以查看和导出任务相关数据，但不能单方彻底删除孩子努力记录。
- 明确安全风险进入人工复核和儿童保护 SOP，AI 不自动报警。
- 任何对外分享默认关闭。

## 13. AI 能力边界

MVP 默认不接真实 AI。后续 AI 只能：

- 拆解愿望。
- 帮助目标可执行化。
- 给出奖励等级建议和理由。
- 转译沟通语气。
- 润色留言或日记。
- 提供修复方案建议。

AI 不能：

- 替双方签约。
- 替家庭做最终裁决。
- 判定谁胜诉。
- 自动发送关键内容。
- 自动报警。
- 泄露 ChildNote 原文。
- 美化失信或篡改事实。

## 14. Demo 成功标准

一个家庭能在 5 分钟内创建第一个小约定，并在当天完成、确认、回应、留下纪念。

必须通过：

- parent 能完成创建家庭、原则确认、奖池初始化。
- parent 能创建首个小约定。
- child 能确认愿望并开始愿望番茄钟。
- child 能提交一句复盘。
- parent 能选择已兑现、延期或待复盘。
- 系统能生成亲子日记。
- 愿望后院出现安静猫来访。
- parent 不能查看 ChildNote。
- witness 不能查看 Evidence、ChildNote、金额、争议详情。
- 已确认契约不能被覆盖，只能生成新版本。
- 所有关键操作有 AuditLog。
- 不可建模契约被拦截。
- 没有学校、机构、商家、托管、视频、强锁、开放社交功能。

## 15. MVP 核心指标

| 指标 | 定义 |
|---|---|
| 首次设置完成率 | parent 完成原则确认和奖池初始化比例 |
| 首个小约定创建率 | 完成设置后创建首个约定比例 |
| 孩子开始守约率 | child 确认愿望后点击开始比例 |
| 首个约定完成率 | 任务完成并提交复盘比例 |
| 家长回应率 | child 达成后 parent 选择兑现/延期/复盘比例 |
| 亲子日记生成率 | 约定完成后生成日记比例 |
| 第二个约定创建率 | 家庭创建第二个约定比例 |
| 7 日家庭留存率 | 家庭 7 日内仍有至少一次有效行为 |
