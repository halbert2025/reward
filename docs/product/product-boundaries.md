# Reward 产品边界与长期不做清单

本文用途：作为 Reward 的硬产品边界。任何开发、设计、文案、数据模型、API、埋点和测试任务都必须先检查本文件。

## Hard Boundaries

Reward 是家庭愿望契约系统，不是家长控制软件、学校管理工具、机构完课工具、奖励商城、支付托管平台或儿童社交平台。

## 永久不做

| 不做项 | 原因 | 替代方案 |
|---|---|---|
| 学校/老师端正式场景 | 会变成教育管理、排名和责任复杂系统 | 只做家庭端 |
| 机构路径 | 机构有获客、续费、完课目标，破坏中立性 | 不接机构版 |
| 商家导购/商品抽佣 | 家长会怀疑奖励建议动机 | 只从家庭用户订阅收费 |
| 支付托管/奖励钱包/资金池 | 涉及未成年人支付、退款、资金沉淀和监管风险 | 只记录承诺和兑现提醒 |
| 视频监督/全天监控 | 高隐私风险，孩子会把产品视为敌人 | 轻证据、番茄钟、复盘、家长确认 |
| 默认强锁手机 | 会滑向控制软件 | 孩子主动开始守约 |
| 开放儿童社交 | 隐私、欺凌、审核和陌生人风险高 | 后置展示型小院名片，默认关闭 |
| 同校/班级/小区数据池 | 小样本重识别和攀比风险高 | 家长端大样本低攀比灵感库 |
| 抽卡式惊喜 | 未成年人概率刺激和消费诱导风险 | 进度式惊喜、愿望星星、里程碑 |
| AI 裁判/自动报警 | 家庭争议不能交给模型判案 | AI 只建议、拆解、转译、提醒 |

## 不可建模清单

以下内容不能作为奖励、惩罚或契约条件：

- 食物、水、睡眠、医疗、药物、衣物、安全住所、基本照顾。
- 爱、陪伴、拥抱、被尊重、被倾听、人格尊严。
- 不被体罚、不被羞辱、不被赶出家门、不被威胁。
- 过度运动、熬夜学习、不就医、不休息。
- 身体接触、隐私暴露、录制私密内容。
- 作弊、撒谎、攻击同学、违法违规行为。
- 不许哭、不许表达、不许拒绝、无条件服从。

## MVP 不做

- 完整 AI。
- 完整约定修复中心。
- 完整见证人分级。
- 真实支付。
- 真实推送。
- 低攀比灵感库。
- 能力归档。
- 时光邮局。
- 年度报告。
- 小院分享。

## 代码审查底线

出现以下任一项，必须阻断合并：

- parent 可以默认读取 ChildNote 内容。
- witness 可以读取 Evidence、ChildNote、奖励金额或争议详情。
- 已确认 Contract 被覆盖，而不是生成 ContractVersion。
- 关键状态转换没有 AuditLog。
- 出现学校、机构、托管、导购、视频、强锁、开放社交或抽卡主链路。
