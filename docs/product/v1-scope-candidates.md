# Reward V1 Scope Candidates

Date: 2026-05-26  
Stage: P12 V1 Scope Reopen

## Current Decision

V1 scope is not reopened yet. The project has not collected real first-batch pilot feedback, so V1 candidates remain hypotheses.

## Candidate Backlog

| Candidate | Evidence Needed | Privacy / Safety Impact | Current Decision |
| --- | --- | --- | --- |
| Real photo upload | Multiple families need it after mock evidence | High: faces, locations, school signs | Not now |
| Real push notifications | Families miss in-app reminders | Medium: notification consent and fatigue | Not now |
| Kimi/AI wording assistant | Parents need help writing gentle responses | High: redaction, opt-out, failure fallback | Not now |
| Stronger witness flow | Families value memory witness | Medium: access boundary | Observe |
| Low-comparison inspiration library | Families need idea support | Low/medium: avoid ranking and comparison | Observe |
| Ability archive | Children like seeing growth | Medium: avoid scoring pressure | Observe |
| Time mailbox | Families want delayed memory | Medium: retention rules | Later |
| Multi-child / multi-parent | Test families have more complex homes | Medium: permissions complexity | Observe |
| Membership / Pro | Business model exploration | High product distraction | Later |

## Rule

No candidate moves into V1 without:

- Real pilot evidence.
- Privacy and safety assessment.
- Clear owner.
- Test plan.
- No conflict with Reward's non-control principle.
