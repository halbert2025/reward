# Reward HTML 原型评审稳定入口

本文用途：兼容早期 Prompt 中的 `docs/design/prototype-review.md` 路径。本文不复制完整 HTML 原型，避免实现误把原型当最终 UI。

## Canonical 来源

- HTML 原型提炼：`docs/source/extracted/html-prototype-notes.md`
- 页面规格：`docs/design/screen-spec.md`
- 用户流程：`docs/design/user-flows.md`
- 文案库：`docs/design/copywriting.md`
- 设计系统草案：`docs/design/design-system.md`

## 使用规则

前端实现必须优先读取 `docs/design/screen-spec.md`，不要直接照搬 HTML 原型结构。

视觉实现应遵守 `docs/design/design-system.md`，避免强红点、排行榜、抽卡语言、赛博炫光和商业手游式高刺激 UI。
