# Reward 文案库与禁用词

本文用途：定义 Reward 的产品人格、端侧语气、禁用表达和推荐表达。所有页面、toast、错误提示、空状态和按钮文案都应遵守本文。

## 1. 产品人格

| 人格 | 文案表现 |
|---|---|
| 家庭契约教练 | 帮家庭把目标、奖励、证据、时间说清楚 |
| 温柔史官 | 记录事实，不改写历史，不审判人格 |
| 协商主持人 | 回到原始规则，帮助双方表达和修复 |
| 孩子努力保护者 | 强调努力被记录，不让记录被单方抹掉 |
| 愿望世界建设者 | 让孩子感觉努力会点亮自己的愿望后院 |

## 2. 家长端文案原则

- 强调省心、清楚、及时回应。
- 不让家长感觉被审判或被孩子举报。
- 对延期和复盘使用温和表达。
- 对不可建模内容坚定拦截，但给替代方案。
- 不使用“失信”“违约”“投诉”作为默认前台词。

推荐表达：

- 这个约定正在等待回应。
- 孩子已经提交完成记录。
- 如果今天不方便兑现，可以说明原因并设置新的兑现时间。
- 我们先回到当初说好的规则。
- 这个内容不适合做成家庭约定，可以换成更清楚、更安全的习惯目标。

## 3. 孩子端文案原则

- 强调愿望、努力、记录、后院变化。
- 不强调监督、打卡、失败和惩罚。
- 退出时给体面空间。
- 私密内容要明确“只给自己看”。
- 完成后给低刺激正反馈，不做强红点和抽卡语言。

推荐表达：

- 准备好了吗？开始为愿望充能。
- 你的努力已经被记录下来了。
- 如果这次先停下，写一句原因就好。
- 这张小纸条默认只给你自己看。
- 今天的小院已经更新啦，去做点别的吧，猫猫会等你回来。

## 4. 见证人端文案原则

- 强调祝福、纪念、轻见证。
- 不使用裁定、监督、举报、围观表达。
- 明确见证人看不到隐私、金额、证据和争议。

推荐表达：

- 你被邀请见证一个家庭小约定。
- 这里只展示约定摘要和完成纪念。
- 你可以送一句祝福。
- 见证人不会看到孩子的小纸条、证据照片或家庭争议。

## 5. 修复/待复盘文案原则

MVP 不做完整约定修复中心，但 P09 可保留“待复盘”入口。

推荐表达：

- 这个愿望需要一起商量一下。
- 先保留这次努力记录，稍后再复盘。
- 新要求可以写进下一份约定，本次先回到原规则。
- 如果今天无法兑现，请写清原因和新的时间。

## 6. 禁用词与替代表达

| 禁用/慎用 | 替代表达 |
|---|---|
| 你违约了 | 这个约定正在等待回应 |
| 家长失信 | 这次回应还没有完成 |
| 孩子投诉你 | 孩子希望这个约定再商量一下 |
| 监督家长 | 提醒约定回应 |
| 监督孩子 | 记录守约过程 |
| 锁住孩子 | 开始守约 |
| 强制完成 | 准备好后开始 |
| 任务失败 | 这次先停下了 |
| 你没有完成 | 这次还没有完成记录 |
| 系统判定你错了 | 我们先回到原始规则 |
| AI 判定 | 系统建议 |
| 惩罚 | 调整规则 |
| 执法 | 记录和提醒 |
| 举报 | 请求复盘 |
| 仲裁 | 约定复盘 |
| 裁判 | 见证 |
| 排行榜 | 纪念册 |
| 抽卡/爆率/SSR/十连/保底/欧皇/氪金 | 小院更新、愿望能量、纪念卡 |

## 7. 通用按钮文案

| 场景 | 主按钮 | 次按钮 |
|---|---|---|
| P01 欢迎 | 创建第一个家庭约定 | 继续已有家庭 |
| P02 原则 | 我理解并继续 | 返回 |
| P03 奖池 | 生成家庭奖池 | 先保存 |
| P04 契约 | 邀请孩子确认 | 保存草稿 |
| P05 邀请 | 复制邀请链接 | 切换到孩子端预览 |
| P06 后院 | 开始守约 | 看看约定 |
| P07 番茄钟 | 我完成了 | 先停一下 |
| P08 提交 | 提交完成记录 | 跳过照片 |
| P09 回应 | 保存回应 | 稍后再看 |
| P10 日记 | 回到小院 | 创建下一个约定 |

## 8. 错误与权限文案

- 这部分内容只对孩子自己可见。
- 见证人只见证完成纪念，不查看证据细节。
- 已确认的约定不能直接改写，可以一起生成新版本。
- 这个约定已经有更新，请刷新后再继续。
- 这次没有保存成功，请再试一次。

## 9. 明确禁止

不得出现：

- 羞辱孩子的表达。
- 审判家长人格的表达。
- 鼓励亲友围观和施压的表达。
- 强锁、监控、录像、实时定位相关表达。
- 商品导购、抽卡、稀有度、概率刺激表达。
- AI 裁决、自动报警、自动替家庭决定的表达。
